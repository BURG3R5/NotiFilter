NotiFilter is a free and open-source Android app that listens to all device notifications and
quietly manages those that match filters created by the user. It does not have permission to access
the internet.

- Features are executed on-device.
- App data is stored on-device, and is necessary for the core features of the app.
- Permissions are incrementally requested according to features used.
- There are no trackers, telemetry, or advertising SDKs.

If the app crashes, the user can choose to email an [ACRA](https://www.acra.ch/) crash report to the
developer. The user can choose to add to comments to the report or the email's body. Reports contain
standard anonymous technical data that is only used for debugging and patching the code.
